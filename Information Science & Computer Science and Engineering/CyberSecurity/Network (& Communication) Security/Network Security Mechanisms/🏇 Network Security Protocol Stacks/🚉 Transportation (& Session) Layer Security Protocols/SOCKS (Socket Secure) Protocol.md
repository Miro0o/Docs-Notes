## Intro
> 🔗 https://en.wikipedia.org/wiki/SOCKS

**SOCKS** is an [Internet](https://en.wikipedia.org/wiki/Internet "Internet") [protocol](https://en.wikipedia.org/wiki/Protocol_\(computing\) "Protocol (computing)") that exchanges [network packets](https://en.wikipedia.org/wiki/Packet_\(information_technology\) "Packet (information technology)") between a [client](https://en.wikipedia.org/wiki/Client_\(computing\) "Client (computing)") and [server](https://en.wikipedia.org/wiki/Server_\(computing\) "Server (computing)") through a [proxy server](https://en.wikipedia.org/wiki/Proxy_server "Proxy server"). **SOCKS5** optionally provides [authentication](https://en.wikipedia.org/wiki/Authentication "Authentication"), so only authorized users may access a server. Practically, a SOCKS server proxies TCP connections to an arbitrary IP address and provides a means for UDP packets to be forwarded. The SOCKS protocol operates between the [application layer](https://en.wikipedia.org/wiki/Application_layer "Application layer") and the [transport layer](https://en.wikipedia.org/wiki/Transport_layer "Transport layer"). A SOCKS server accepts incoming client connection on TCP port 1080.
