## Intro
> 🔗 https://en.wikipedia.org/wiki/Standard_ML

**Standard ML** (**SML**) is a [general-purpose](https://en.wikipedia.org/wiki/General-purpose_programming_language "General-purpose programming language"), [high-level](https://en.wikipedia.org/wiki/High-level_programming_language "High-level programming language"), [modular](https://en.wikipedia.org/wiki/Modular_programming "Modular programming"), [functional](https://en.wikipedia.org/wiki/Functional_programming "Functional programming") [programming language](https://en.wikipedia.org/wiki/Programming_language "Programming language") with compile-time [type checking](https://en.wikipedia.org/wiki/Type_checking "Type checking") and [type inference](https://en.wikipedia.org/wiki/Type_inference "Type inference"). It is popular for writing [compilers](https://en.wikipedia.org/wiki/Compiler "Compiler"), for [programming language research](https://en.wikipedia.org/wiki/Programming_language_research "Programming language research"), and for developing [theorem provers](https://en.wikipedia.org/wiki/Automated_theorem_proving "Automated theorem proving").

Standard ML is a modern dialect of [ML](https://en.wikipedia.org/wiki/ML_\(programming_language\) "ML (programming language)"), the language used in the [Logic for Computable Functions](https://en.wikipedia.org/wiki/Logic_for_Computable_Functions "Logic for Computable Functions") (LCF) theorem-proving project. It is distinctive among widely used languages in that it has a [formal specification](https://en.wikipedia.org/wiki/Formal_specification "Formal specification"), given as [typing rules](https://en.wikipedia.org/wiki/Typing_rule "Typing rule") and [operational semantics](https://en.wikipedia.org/wiki/Operational_semantics "Operational semantics") in _The Definition of Standard ML_, originally released in 1990, with a second and final revision being released in 1997.
