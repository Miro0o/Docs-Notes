## Intro
> 🔗 https://en.wikipedia.org/wiki/ML_(programming_language)

**ML** (Meta Language) is the [metalanguage](https://en.wikipedia.org/wiki/Metalanguage "Metalanguage") developed for the [Edinburgh LCF theorem prover](https://en.wikipedia.org/wiki/Logic_for_Computable_Functions "Logic for Computable Functions") in the 1970s. It is an early [statically typed](https://en.wikipedia.org/wiki/Static_type "Static type"), [functional language](https://en.wikipedia.org/wiki/Functional_programming "Functional programming") with [polymorphic](https://en.wikipedia.org/wiki/Polymorphism_\(computer_science\) "Polymorphism (computer science)") [type inference](https://en.wikipedia.org/wiki/Type_inference "Type inference") in the [Hindley–Milner](https://en.wikipedia.org/wiki/Hindley%E2%80%93Milner_type_system "Hindley–Milner type system") style, and other features like [exceptions](https://en.wikipedia.org/wiki/Exception_handling_\(programming\) "Exception handling (programming)") and [mutable variables](https://en.wikipedia.org/wiki/Mutable "Mutable"). ML's design in LCF directly inspired the later ML family (notably [Standard ML](https://en.wikipedia.org/wiki/Standard_ML "Standard ML"), [Caml](https://en.wikipedia.org/wiki/Caml "Caml"), and their derivatives) and influenced subsequent functional language development
