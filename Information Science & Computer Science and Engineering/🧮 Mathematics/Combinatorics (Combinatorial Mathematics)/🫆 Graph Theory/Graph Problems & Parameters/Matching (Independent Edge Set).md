## Intro
> 🔗 https://en.wikipedia.org/wiki/Matching_(graph_theory)

In the mathematical discipline of [graph theory](https://en.wikipedia.org/wiki/Graph_theory "Graph theory"), a **matching** or **independent edge set** in an undirected [graph](https://en.wikipedia.org/wiki/Graph_\(discrete_mathematics\) "Graph (discrete mathematics)") is a set of [edges](https://en.wikipedia.org/wiki/Edge_\(graph_theory\) "Edge (graph theory)") without common [vertices](https://en.wikipedia.org/wiki/Vertex_\(graph_theory\) "Vertex (graph theory)"). In other words, a subset of the edges is a matching if each vertex appears in at most one edge of that matching.

Finding a [largest matching](https://en.wikipedia.org/wiki/Maximum-cardinality_matching "Maximum-cardinality matching") in a [bipartite graph](https://en.wikipedia.org/wiki/Bipartite_graph "Bipartite graph") can be treated as a [network flow](https://en.wikipedia.org/wiki/Flow_network "Flow network") problem. Finding a largest matching in a general graph is much more difficult; it can be done using [Edmonds'](https://en.wikipedia.org/wiki/Jack_Edmonds "Jack Edmonds") [blossom algorithm](https://en.wikipedia.org/wiki/Blossom_algorithm "Blossom algorithm").
